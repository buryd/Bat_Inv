# Battery backup

120 V pure-sine backup for a refrigerator, a CPAP, and LED lights.

- [Design](DESIGN.md) — loads, equipment, and wiring
- [Bill of materials](BOM.md) — parts and October 2026 US price ranges

Parts for the default system are about **$1,411–$3,004** before tax and shipping. One 24 V 150 Ah LiFePO4 battery and a 1,000 W inverter make up most of that.
